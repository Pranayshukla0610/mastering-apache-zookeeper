# mastering-apache-zookeeper
A distributed systems project demonstrating Apache ZooKeeper fundamentals, cluster coordination, configuration management, synchronization services, and integration with modern Data Engineering platforms like Kafka.

---

## Tech Stack

- Apache ZooKeeper
- Apache Kafka
- Docker
- Docker Compose
- Linux
- Bash Scripting

---

## Features

- Distributed coordination service
- Cluster synchronization
- Configuration management
- Leader election concepts
- Kafka-ZooKeeper integration
- Dockerized setup
- Fault-tolerant architecture
- Service orchestration
